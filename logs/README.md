# Logs

This folder contains TensorBoard logs and training metadata generated by experiment runs.

## Purpose

Logs are used to:

- monitor training/validation trends in TensorBoard
- compare runs across models and datasets
- track hyperparameters and run versions

## Current structure

```text
logs/
├── binary_EV/
├── multiclass_EV/
├── re-training_EV/
├── unified_training_EV/
├── unified_training_EV_ced/
└── unified_training_EV_clap/
```

Typical run content:

```text
logs/<experiment_name>/version_X/
├── events.out.tfevents.*
└── hparams.yaml
```

## External hosting (large artifacts)

To reduce repository size, complete log archives are available from external storage.

- Download link (placeholder): `<<ONEDRIVE_LOGS_LINK>>`

After download:

1. extract the archive
2. copy the extracted content into this folder (`logs/`)
3. keep original folder hierarchy to preserve TensorBoard run paths

Then launch TensorBoard from project root:

```bash
tensorboard --logdir logs/
```
